# Utility Desk and Utility Desk Lite comparison

Utility Desk Lite adapts the local Utility Desk to browser capabilities. This
table describes current source behavior and its limits; it does not verify
deployed releases. The app's `package.json` owns its version.

| Tool or behavior | Static edition | Difference from the original |
| --- | --- | --- |
| Date & time | Calendar shifts, differences, seconds/milliseconds, IANA timezones, missing-time rejection, earlier/later repeated-time selection, all original world-clock cities | Uses browser timezone data instead of OS Python timezone data |
| Media converter | MP4/MKV H.264/AAC, WebM VP9/Opus, MP3/M4A/WAV/Opus, extra OGG/GIF, quality, maximum height, audio bitrate, From/To, browser duration detection, filename, preview, progress and cancel | Bundled single-thread FFmpeg; 256 MB input limit; blank To converts through the source’s end, with detected duration shown as a hint; metadata detection uses browser playback instead of ffprobe; no native output-folder selection |
| Document converter | TXT/Markdown/HTML/basic EPUB/classic MOBI, PDF → EPUB/Markdown/text/HTML, EPUB/Markdown → searchable paginated A4 PDF, title/author, filename and text preview | Text reflow only: no OCR, images, exact PDF layout, complex tables, AZW3/KF8, DRM or Calibre fidelity; 50 MB, 1,000 PDF pages and 2 million text characters; PDF fonts cover Latin, Greek and Cyrillic, with unsupported glyphs reported |
| PDF to images | PNG/JPEG, 72–1,200 DPI, JPEG quality, selected pages, crop-box rendering, annotation toggle, individual/ZIP downloads, bundled fonts/CMaps | TIFF export and full media-box option unavailable; 50 MP per-page memory guard and a 500 MB total output guard; PDF.js instead of Poppler |
| Images to PDF | Ordered inputs, image-sized/A4/Letter pages, orientation, DPI, fitting, margin, filename | No extra paper sizes and no PDF preview (only the original has "Preview PDF"); browser-decodable formats only, no TIFF/RAW/HEIC; JPEG photos stay JPEG, other formats are stored losslessly; browser PDF generation instead of ImageMagick |
| Merge PDFs | Reordering, selected pages in entered order including repetitions, filename; waits for selected batches to finish validation | Unencrypted inputs, size guards; document-level bookmarks and metadata are omitted; forms/links may need review |
| Split PDF | Selected pages in both modes; separate files deduplicate/use original page numbers; one-file extraction preserves entered order/repetitions; ZIP download | No page preview; unencrypted inputs, browser downloads instead of new native output folder; bookmarks/metadata omitted; 500 MB total output guard |
| Compress PDF | Lossless stream/object optimization retaining text, metadata, links and forms; balanced/smaller-file JPEG page modes, actual size/savings, cancellation, download and unchanged-copy fallback | Native qpdf modes preserve text and optimize eligible non-JPEG images. Browser image modes rasterize visible crop-box pages at 150/96 DPI, flatten links/forms and remove selectable text; 200 MB, 1,000 pages, 50 MP per rendered page |
| Unlock PDF | Known opening/owner password or empty-password decryption; pages, metadata, links and forms retained; cancellable worker; passwords never persisted | Bundled @cantoo/pdf-lib instead of local qpdf; 200 MB and 1,000-page limits; no local output-folder selection |
| QR generator | Type dropdown for text/links, Wi-Fi (WPA/WPA2, WEP, open, hidden), email, phone, SMS and vCard contacts; PNG/SVG export, size and error correction, four-module quiet zone | Same payload builders, validation, defaults and qrcode library, entirely local in both editions (a shared set of fixed payload tests keeps them equal). The hint wording and the text field rows now match. The draft lifecycle differs on purpose: Lite clears every field when you leave the tool, the original keeps the draft until reload. Smaller implementation differences: Lite cleans the file name with its shared file-name rule (`/` and `\` become `_`, reserved names get a `_` prefix, at most 120 characters), the original strips reserved characters (at most 100); downloads use an object URL in Lite |
| Crop Image | Separate utility with one crop preview, removed-edge pixels and area percentage; exact crop export as PNG/JPEG/WebP | Browser-decodable inputs and 100 MP limit; native uses ImageMagick and also exports TIFF/GIF/BMP/AVIF |
| Compress Image | Separate utility with live resize preview; JPEG/WebP quality, lossless PNG, strict decimal KB/MB limit, optional resizing | PNG/JPEG/WebP output only; browser-decodable inputs, 200 MB and 100 MP limits; metadata removed and camera orientation applied; JPEG source transparency stays white even with black padding; animated inputs export a single frame |
| Image workshop | Rotate, flip, color style, automatic/manual contrast, sharpening and live preview; resizing, quality and size limits live in Compress Image | PNG/JPEG/WebP output only; no native GIF/TIFF/BMP/AVIF encoder; camera orientation is always corrected and metadata always stripped, retaining EXIF/profiles is unavailable; previews of images over 1,200 px use a reduced copy, exports use the full image |
| Cancellation and state | One operation at a time; controls frozen while running; cancellation on navigation; pending image/PDF canvas encoders release immediately and ignore late output; source-based filenames survive same-source reselection; form drafts flush on navigation | Browser decoding and individual pdf-lib steps cannot always be interrupted. Tool drafts stay in memory until reload; the last 30 activity entries (tool, status, message, which can contain file names) persist in the browser's localStorage, without native process logs |

Folder sync, Media downloader and Secure copy are available only in the local Utility Desk. A static host cannot access arbitrary local paths or invoke the original system executables.
